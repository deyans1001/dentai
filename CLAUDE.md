# CLAUDE.md — DentAI

## What is this?
AI receptionist SaaS for dental clinics in Bulgaria. All UI in Bulgarian.

## Stack
Next.js 14 App Router, TypeScript, Tailwind, Supabase, Anthropic Claude API, Stripe, Resend, Google Calendar API, Retell AI

## Rules
1. ALL text in Bulgarian
2. Mobile-first (360px min)
3. Dark theme: bg #070d1b, text #e2e8f0, primary #3b82f6, accent #f59e0b, success #22c55e, danger #ef4444, purple #8b5cf6
4. Fonts: "Outfit" headings, "Plus Jakarta Sans" body (Google Fonts)
5. Every API call in try-catch with Bulgarian errors
6. Loading skeletons everywhere
7. No `any` types
